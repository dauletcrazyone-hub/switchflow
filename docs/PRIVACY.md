# Политика конфиденциальности SwitchFlow

**Коротко:** SwitchFlow не собирает, не хранит у себя и не отправляет в интернет ваши данные.

## Какие данные обрабатываются
Только те категории, которые вы сами выбрали для переноса: фото, видео, контакты,
календари, документы, музыка. Приложения на телефонах запрашивают доступ только к ним.

## Куда передаются данные
Только между вашими телефонами и вашим компьютером — по локальной сети или кабелю.
Компьютер не делает исходящих соединений в интернет. Соединение шифруется (TLS),
а телефон проверяет подлинность компьютера по отпечатку сертификата из QR-кода.

## Что хранится на компьютере
- Временные копии файлов во время переноса — в папке временных файлов
  (по умолчанию `%LOCALAPPDATA%\app.switchflow.desktop\staging`). Каждая копия удаляется,
  как только получатель подтвердил сохранение; остальные — при отмене или закрытии отчёта.
- Резервные копии — только если вы их создали, в выбранной вами папке.
- История переносов: даты, имена устройств, количества и размеры. Без имён файлов.
- Журнал доставленного: хэши идентификаторов, чтобы не отправлять одно и то же дважды.
- Журналы работы: без имён файлов, контактов, событий и содержимого.
- Сопряжённые телефоны (`devices.json`): модель, имя телефона, версия системы и SHA-256 ключа
  сопряжения — сам ключ не хранится. Удаляется кнопкой «Отключить телефон» или «Сбросить ключи и сопряжения».

## Драйвер для переноса по кабелю
Установщик ставит USB-драйвер UsbDk (Red Hat, открытый исходный код). Через него SwitchFlow
переводит Android-телефон в режим кабеля и, пока программа запущена, скрывает такие телефоны от
других драйверов Windows. Обычные USB-устройства (диски, мыши, камеры) SwitchFlow не открывает:
только устройства производителей телефонов с интерфейсом телефона (MTP, PTP, MIDI, USB-модем).

## Что хранится на телефонах
- Ключ сопряжения с компьютером (Android — приватное хранилище приложения, исключено из
  резервного копирования; iOS — Keychain, только это устройство).
- Временные экспортные файлы контактов и календарей удаляются после переноса.

## Оригиналы
SwitchFlow никогда не изменяет и не удаляет данные на телефоне-источнике.

## Удаление данных
Настройки → «Очистить историю», «Сбросить ключи и сопряжения». Удаление приложения
удаляет все его данные на устройстве.
