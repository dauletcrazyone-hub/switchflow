# Установка SwitchFlow на iPhone без Mac (Sideloadly)

Облачная сборка готовит **неподписанный** файл приложения `SwitchFlow-<версия>-unsigned.ipa`.
Программа **Sideloadly** на Windows подписывает его вашим Apple ID и ставит на iPhone по кабелю.
Платный аккаунт Apple Developer не нужен.

| | Бесплатный Apple ID |
|---|---|
| Срок работы установленного приложения | **7 дней**, потом переустановить (данные сохраняются) |
| Сколько таких приложений одновременно | 3 |
| Новых идентификаторов приложений | не больше 10 за 7 дней |
| Нужен | iPhone с iOS 16 или новее, кабель USB, ПК с Windows 10/11 |

## 1. Скачайте .ipa

1. GitHub → репозиторий **switchflow** → вкладка **Actions** → workflow **iOS**.
2. Откройте последний прогон с зелёной галочкой → внизу раздел **Artifacts** → **ios-ipa**.
3. Скачается zip-архив, внутри — `SwitchFlow-0.1.0-unsigned.ipa`. Распакуйте его.

Или из командной строки:

```bash
gh run list --workflow ios.yml --limit 5
```

```bash
gh run download <id> -n ios-ipa
```

Файл хранится 30 дней; новая сборка появляется при каждом изменении в `ios/`.
Это сборка Release: отладочных лазеек для облачного теста в ней нет (сборка это проверяет).

## 2. Подготовьте ПК

1. Установите **iTunes** и **iCloud** с сайта apple.com — именно версии «для Windows» с сайта,
   **не** из Microsoft Store (Sideloadly работает только с ними).
2. Скачайте и установите **Sideloadly** с официального сайта sideloadly.io.

## 3. Подключите iPhone

1. Подключите iPhone кабелем и разблокируйте.
2. На iPhone появится «Доверять этому компьютеру?» → **Доверять**, введите код-пароль.

## 4. Установите приложение

1. Запустите Sideloadly.
2. Перетащите `SwitchFlow-0.1.0-unsigned.ipa` в окно (большая кнопка с иконкой IPA).
3. В поле **iDevice** выберите свой iPhone.
4. В поле **Apple account** введите Apple ID и нажмите **Start**.
5. Введите пароль Apple ID и, если спросит, код двухфакторной проверки с iPhone.
6. Дождитесь надписи **Done**.

> **Про пароль.** Sideloadly — сторонняя программа, и пароль от Apple ID вводится в неё.
> Надёжнее завести **отдельный Apple ID** только для установки тестовых приложений и не
> использовать основной (с покупками, фото в iCloud и т. п.).

## 5. Разрешите запуск на iPhone

1. **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить.
   iPhone перезагрузится и после разблокировки спросит ещё раз — **Включить**.
   (Пункт появляется только после установки приложения через Sideloadly.)
2. **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
   Для этого шага нужен интернет.
3. Откройте **SwitchFlow** на iPhone.

## 6. Подключите к программе на ПК

1. ПК и iPhone должны быть в **одной сети Wi-Fi** (гостевые сети часто запрещают устройствам
   видеть друг друга).
2. На ПК в SwitchFlow нажмите **«Показать QR-код»**.
3. На iPhone нажмите **«Подключиться к компьютеру»**, разрешите доступ к камере и отсканируйте код.
4. iPhone спросит доступ к **локальной сети** — **Разрешить**, иначе он не увидит ПК.
5. Сверьте 6 цифр на iPhone и ПК и нажмите **«Разрешить»** на ПК.

Дальше — как с Android: выберите категории, iPhone попросит доступ только к ним.

## Через 7 дней

Приложение перестанет открываться. Повторите шаг 4 с тем же Apple ID — оно установится поверх,
сопряжение и настройки сохранятся. В Sideloadly можно включить автоматическое продление подписи,
когда iPhone и ПК в одной сети.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| Sideloadly не видит iPhone | Установите iTunes с сайта apple.com (не из Microsoft Store), разблокируйте iPhone, переподключите кабель, нажмите «Доверять» на iPhone (после обновления iTunes iPhone спрашивает снова), перезапустите Sideloadly |
| `Apple's login server refused the request (HTTP 503)` | Apple временно не пускает вход: подождите 30 минут **без повторных попыток** (каждая продлевает блокировку). Вход идёт через «Local Anisette», которой нужен свежий iTunes 12 x64 с apple.com — старый iTunes (11 и раньше) её ломает. Если Sideloadly пишет, что Local Anisette отключена, — ⚙ → **Recover** |
| «Ненадёжный разработчик» при запуске | Шаг 5.2: «VPN и управление устройством» → Доверять (нужен интернет) |
| «Режим разработчика» не найден | Сначала установите приложение (шаг 4), затем пункт появится |
| Ошибка про лимит приложений | На бесплатном Apple ID — не больше 3 таких приложений: удалите лишнее |
| Ошибка, что идентификатор приложения недоступен | В Sideloadly → **Advanced options** → измените Bundle ID, например `app.switchflow.companion.<ваше-имя>` |
| iPhone не подключается к ПК | Одна сеть Wi-Fi; **Настройки → SwitchFlow → Локальная сеть** — включено; брандмауэр Windows разрешает SwitchFlow (установщик добавляет правило сам) |
| Приложение перестало открываться | Прошло 7 дней — переустановите (раздел выше) |

## Что проверить на iPhone

Это первый запуск на настоящем iPhone: до сих пор приложение проверялось только в симуляторе
([STATUS.md](STATUS.md)). Безопасный порядок проверки:

1. Сопряжение по QR и сверка 6 цифр.
2. **Резервная копия iPhone → ПК** — только читает данные на iPhone, ничего на нём не меняет.
3. Восстановление на iPhone — лучше на тестовом iPhone или с небольшой тестовой копией:
   SwitchFlow добавляет фото и контакты, не удаляя существующие, но добавленное придётся
   удалять вручную.
