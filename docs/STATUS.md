## Проверка на втором устройстве: Galaxy A25, Android 16 (21.10.2026)

Устройство: **Samsung Galaxy A25 (SM-A256E), Android 16 (SDK 36)** — личный телефон владельца.
По его просьбе проверка **только чтением**: ничего не копировалось и не переносилось.

| Шаг | Результат |
|---|---|
| Сопряжение по Wi-Fi (сеть ПК помечена Windows как «Общедоступная») | ✅ |
| Разрешения Android 16: одна карточка в приложении → системные диалоги фото/видео, аудио, контактов | ✅ все выданы |
| Подсчёт большой медиатеки (около 16 с после разрешений) | ✅ фото **11 956** (5,2 ГБ, 11 альбомов), видео **3 726** (18 ГБ), музыка **6 627**, события 0 — совпадает с MediaStore/CalendarProvider |
| Контакты | ✅ 1 881 из 1 883: 2 пустых контакта (без имени и данных) пропущены намеренно |
| Отображение на ПК | ✅ большие числа и объёмы выводятся корректно |
| Отключение | ✅ временные `contacts.vcf` и `calendar-events.json` удалены с телефона, токен сопряжения удалён |

Найдено и исправлено:
- **Несколько отмеченных категорий подряд → «Считаем…» навсегда.** Каждая галочка отправляла отдельный запрос,
  и на телефоне новая карточка разрешений заменяла предыдущую; запросы для фото, видео, музыки и контактов
  ждали бесконечно. Теперь ПК объединяет галочки за 0,5 с в один запрос, телефон показывает запросы
  разрешений по очереди, а при долгом ожидании появляется «Запросить снова».
- **Пустая категория блокировала кнопку старта** (календарь без событий оставался отмеченным).
  Теперь пустые категории снимаются автоматически (регрессионный тест в `CategoryPanel.test.tsx`).

## Подтверждённо работающие функции

Проверено автоматическими тестами, запуском на Windows 11 и на телефонах (см. выше).

### Windows-приложение
- Запуск, собственная строка заголовка (свернуть/развернуть/закрыть), окно появляется без белой вспышки.
- Навигация: Главная, История, Резервные копии, Настройки, Помощь, О программе.
- Светлая и тёмная темы, режим «как в системе», плавная смена темы (View Transitions).
- Анимации: появление приложения, переходы экранов, обнаружение телефона (пульс), появление карточек,
  соединительная линия, световой поток при передаче, плавные проценты, раскрытие категорий,
  микроанимации кнопок/переключателей, анимация завершения, скелетоны. Поддержка «уменьшения движения»
  (системная настройка и переключатель в приложении).
- HTTPS-сервер с самоподписанным сертификатом ECDSA P-256, хранится между запусками.
- QR-сопряжение: одноразовый секрет (10 минут, смена после 5 ошибок), 6-значный код сверки,
  подтверждение на ПК, назначение ролей источник/получатель, смена направления.
- Запрос разрешений только для выбранных категорий; учёт «ограниченного доступа».
- Таблица совместимости для всех 11 категорий × 4 направления с честными статусами.
- Предварительные проверки: связь, доступ к данным, совместимость, разрешения получателя,
  свободное место на получателе и на ПК.
- Движок переноса: загрузка частями по 4–16 МиБ с докачкой, проверка SHA-256 на ПК,
  буфер с обратным давлением (≤ 4 ГиБ), доставка с HTTP Range (открытые и ограниченные диапазоны),
  подтверждение получателем с SHA-256, пауза, возобновление, безопасная отмена, повтор
  неудачных, автопауза при потере связи и продолжение при переподключении, сохранение сессии
  на диск и восстановление после перезапуска ПК, журнал «уже перенесено» (без дублей при повторе).
- Реальные показатели: файлы, объём, скорость (скользящее окно 6 с), оставшееся время.
- Отчёт: перенесено/пропущено/ошибки по категориям, причины ошибок понятным языком.
- История переносов (только числа и размеры), очистка истории.
- Резервные копии на ПК (обычные папки + манифест с SHA-256), список копий, восстановление на телефон,
  защита от подмены путей в манифесте.
- Обнаружение USB: Windows Portable Devices (тип, модель, заряд), iPhone без драйвера Apple
  (SetupAPI), ADB по желанию пользователя + `adb reverse` для подключения по кабелю.
- Журналы без имён файлов и личных данных.
- Демо-режим, явно помеченный.
- Локализация: русский, английский; казахский частично (с откатом на русский).

### Android-компаньон
- Компилируется, APK собирается; модульные тесты vCard (3.0, 2.1 quoted-printable, формат iOS),
  разбора QR, длительностей событий.
- Код: сопряжение с пиннингом сертификата, heartbeat, очередь команд, foreground-сервис dataSync,
  чтение MediaStore (фото/видео/музыка + альбомы), SAF для документов, экспорт контактов в vCard,
  экспорт календарей в JSON, сохранение через MediaStore с `IS_PENDING` и проверкой чтением обратно,
  импорт контактов (объединить/пропустить/оба), импорт событий (с локальным календарём, если нет
  доступного для записи).

### iOS-компаньон
- Код написан (SwiftUI, PhotoKit, Contacts, EventKit, URLSession с пиннингом, Keychain).
- **Собирается в облаке** (GitHub Actions, `.github/workflows/ios.yml`): Xcode 26.3, SDK iOS 26.2 — все 18 файлов
  компилируются без предупреждений, 4 модульных теста проходят, приложение запускается в симуляторе iPhone,
  экран приветствия корректен на русском и английском (скриншоты — в артефакте сборки).
- **Не проверено:** работа на настоящем iPhone (камера, фото, контакты, календари, сеть), перенос с/на iPhone.

## План проверки на устройствах

Минимальный сквозной сценарий (критерий готовности MVP):

1. Соберите и установите Windows-приложение (`docs/BUILD_WINDOWS.md`).
2. Установите APK на два Android-телефона (`adb install app-debug.apk`) или на Android + iPhone (iOS через Xcode).
3. Подключите ПК и телефоны к одной сети Wi-Fi (частная сеть, не гостевая).
4. На ПК: «Показать QR-код» → телефон 1: «Подключиться к компьютеру» → сверить код → «Разрешить». Повторить для телефона 2.
5. Отметить «Фотографии» → на телефоне-источнике нажать «Разрешить» → дождаться количества.
6. «Начать перенос» → на получателе разрешить доступ, если спросит.
7. Проверить: прогресс и скорость меняются; отчёт «Перенос завершён»; фото появились
   в Галерее/Фото (Android: `DCIM/SwitchFlow` или `Pictures/SwitchFlow/<альбом>`).
8. Проверка устойчивости: во время переноса выключить Wi-Fi на получателе на 30 с → перенос
   встаёт на «Ожидание подключения» → включить Wi-Fi → продолжается. Повторный перенос тех же фото —
   все пропущены как «уже перенесённые».
