# Этап 1. Техническая реализуемость SwitchFlow

Документ фиксирует, что реально можно сделать на Windows 10/11, Android и iOS
официальными и документированными средствами. Всё, что здесь помечено как
недоступное, SwitchFlow **не обещает** и не имитирует.

## 1. Каналы связи с телефоном

| Канал | Android | iPhone | Что даёт на самом деле |
|---|---|---|---|
| USB → Windows Portable Devices (WPD/MTP) | ✅ в режиме «Передача файлов» | ⚠️ только если установлен драйвер Apple (приложение «Apple Devices» или iTunes) и нажато «Доверять» | Android: чтение и запись общих папок (DCIM, Download, Music…). iPhone: **только чтение** папки DCIM (фото и видео). Контакты, календари, сообщения через WPD недоступны. |
| USB → ADB | ⚠️ только при включённой «Отладке по USB» и подтверждении RSA-ключа | ⛔ | SwitchFlow использует ADB только для `adb reverse`: приложение-компаньон подключается к ПК по кабелю вместо Wi-Fi. Никакого чтения данных через ADB в обход разрешений. |
| USB → обнаружение (SetupAPI, VID Apple 0x05AC) | — | ✅ | Позволяет честно сказать «iPhone подключён, но драйвер Apple не установлен». |
| Локальная сеть + приложение-компаньон | ✅ | ✅ | Полный доступ к тем категориям, на которые пользователь сам дал разрешение в телефоне: MediaStore, Contacts Provider, CalendarContract, SAF / PhotoKit, Contacts, EventKit, Files. |
| Полный доступ к файловой системе iPhone по USB | — | ⛔ | Невозможно без jailbreak или неофициальных протоколов. SwitchFlow этого не делает. |

**Вывод:** запись на iPhone возможна только через приложение-компаньон
(PhotoKit / Contacts / EventKit). Поэтому основной канал MVP — защищённое
локальное соединение «телефон ↔ ПК» через приложения-компаньоны, а ПК работает
как узел-посредник (источник → ПК → получатель) с проверкой SHA-256 на каждом шаге.

## 2. Матрица категорий данных

Обозначения:
- **Компаньон** — поддерживается SwitchFlow через приложение-компаньон;
- **Действие** — поддерживается, но пользователь должен сделать шаг на телефоне (выбрать файлы, указать календарь);
- **Офиц. инструмент** — возможно только встроенным мастером Apple/Google/производителя или самим приложением;
- **Недоступно** — нет разрешённого механизма.

| Категория | Android → iPhone | iPhone → Android | Android → Android | iPhone → iPhone |
|---|---|---|---|---|
| Фото | Компаньон (MediaStore → PhotoKit) | Компаньон (PhotoKit → MediaStore); USB-чтение DCIM через WPD — этап 2 | Компаньон; MTP | Компаньон (PhotoKit → PhotoKit) |
| Видео | Компаньон | Компаньон | Компаньон | Компаньон |
| Контакты | Компаньон (Contacts Provider → Contacts, vCard) | Компаньон (Contacts → Contacts Provider) | Компаньон | Компаньон |
| Календари (события) | Компаньон (CalendarContract → EventKit) | Действие: на Android нужен календарь, доступный для записи (например, аккаунт Google) | Действие (то же) | Компаньон |
| Напоминания | Недоступно (у Android нет системного API напоминаний) | Недоступно | Недоступно | Офиц. инструмент (iCloud) |
| Документы | Действие: выбрать файлы на Android (SAF); на iPhone попадут в «Файлы › SwitchFlow» | Действие: выбрать файлы в «Файлах» iPhone | Действие: выбрать файлы (SAF) | Действие |
| Музыка (файлы) | Действие: попадут в «Файлы», а не в «Музыку» — iOS не разрешает сторонним приложениям добавлять треки в медиатеку | Недоступно: iOS не даёт экспортировать медиатеку «Музыки» | Компаньон (MediaStore.Audio) | Недоступно (офиц.: синхронизация Apple Music / iCloud) |
| Сообщения (SMS/iMessage) | Офиц. инструмент: «Перенос на iOS» при настройке iPhone | Офиц. инструмент: перенос данных при настройке Android | Офиц. инструмент: перенос при настройке Android | Офиц. инструмент: «Быстрое начало» / iCloud |
| История вызовов | Офиц. инструмент | Офиц. инструмент | Офиц. инструмент | Офиц. инструмент |
| Настройки | Офиц. инструмент | Офиц. инструмент | Офиц. инструмент | Офиц. инструмент |
| Данные приложений | Недоступно (песочница) | Недоступно | Частично: резервная копия Google | Офиц. инструмент (iCloud) |
| WhatsApp | Офиц. инструмент WhatsApp (перенос чатов при настройке) | Офиц. инструмент WhatsApp | Офиц. инструмент WhatsApp | Офиц. инструмент WhatsApp |

Почему сообщения и история вызовов не переносятся компаньоном:
- iOS не предоставляет сторонним приложениям API для чтения или записи SMS, iMessage и журнала звонков.
- На Android чтение и запись SMS требует роли «SMS-приложение по умолчанию», а `READ_CALL_LOG` ограничен политикой Google Play. Подмена SMS-приложения ради переноса — плохой и небезопасный опыт, поэтому SwitchFlow направляет к официальным инструментам.

## 3. Новые и уже настроенные телефоны

| Механизм | Работает на новом телефоне | Работает на настроенном |
|---|---|---|
| SwitchFlow + компаньон | ✅ (после первичной настройки и установки приложения) | ✅ |
| «Перенос на iOS» (Apple) | ✅ только при первоначальной настройке iPhone | ⛔ (нужен сброс iPhone) |
| Перенос при настройке Android / Smart Switch | ✅ при настройке | Частично (зависит от производителя) |
| Перенос чатов WhatsApp | ✅ при настройке WhatsApp | ⛔ (нужно переустановить WhatsApp) |

SwitchFlow честно показывает это различие в карточке категории и в «Помощи».

## 4. Сборка

| Компонент | Где собирается |
|---|---|
| Windows-приложение (Tauri 2, Rust + React) | Windows 10/11, Rust (MSVC) + Visual Studio Build Tools + WebView2 |
| Android-компаньон (Kotlin, Compose) | Windows/macOS/Linux, JDK 17 + Android SDK |
| iOS-компаньон (Swift, SwiftUI) | **Только macOS + Xcode**, учётная запись Apple Developer для установки на устройство. Полноценная нативная сборка iOS на Windows невозможна. |

## 5. Решение для MVP

1. Windows-приложение запускает локальный HTTPS-сервер с самоподписанным сертификатом.
2. Телефон сканирует QR-код, в котором есть адрес ПК, одноразовый секрет и отпечаток сертификата (pinning).
3. Пользователь подтверждает сопряжение на ПК, сверив 6-значный код с экраном телефона.
4. Источник отдаёт файлы на ПК частями по 4 МиБ, ПК проверяет SHA-256 каждого файла.
5. Получатель забирает файлы с ПК (с поддержкой докачки), сохраняет через системные API, перечитывает сохранённое и подтверждает SHA-256.
6. Оригиналы на источнике никогда не изменяются и не удаляются.
