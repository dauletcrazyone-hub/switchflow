# Выпуск SwitchFlow в Microsoft Store — пошагово

## Что уже готово

| Что | Где |
|---|---|
| Пакет MSIX для магазина (не подписан — Microsoft подписывает его сам, поэтому сертификат за 100–400 $ не нужен и окно «Windows защитила ваш компьютер» пропадает) | `desktop/src-tauri/target/release/bundle/msix/SwitchFlow_<версия>_x64.msix` |
| Скрипт сборки пакета | `desktop/src-tauri/windows/package-msix.ps1` |
| Политика конфиденциальности | `docs/store/privacy-policy.html` (та же, что для Google Play) |

Проверено 7.11.2026 на этом ПК: пакет установлен в тестовом режиме, программа открылась,
сервер для телефонов и страница со ссылкой на приложение для Android работали, затем тестовая
установка удалена.

**Отличия от обычного установщика:**
- Пакет из магазина не может сам ставить драйверы. Драйвер кабеля для Android (UsbDk) программа
  предлагает установить кнопкой «Установить драйвер», когда впервые видит Android-телефон на кабеле
  (Windows попросит права администратора). По Wi-Fi и с iPhone всё работает без него.
- Правило брандмауэра (только домашние сети) задаётся в манифесте пакета.
- Обновления ставит сам Microsoft Store.

## Шаг 1. Аккаунт разработчика

1. Откройте <https://storedeveloper.microsoft.com> и зарегистрируйтесь как **частное лицо**
   (Individual). Для частных лиц регистрация бесплатная; Microsoft попросит подтвердить личность.
2. Войдите в Partner Center: <https://partner.microsoft.com/dashboard>.

## Шаг 2. Зарезервировать название

1. **Apps and games → New product → MSIX or PWA app**.
2. Название — «SwitchFlow» (если занято — придумайте другое, я поменяю его в программе).

## Шаг 3. Взять данные для пакета

В приложении: **Product management → Product identity**. Там три строки:
- **Package/Identity/Name** — например `12345Daulet.SwitchFlow`;
- **Package/Identity/Publisher** — например `CN=1A2B3C4D-....`;
- **Package/Properties/PublisherDisplayName** — ваше имя издателя.

Пришлите их мне (это не секрет) — я соберу пакет с ними. Или соберите сами:

```powershell
cd desktop
npm run tauri:build
./src-tauri/windows/package-msix.ps1 -IdentityName "<Name>" -Publisher "<Publisher>" -PublisherDisplayName "<Имя издателя>"
```

## Шаг 4. Цена

**Pricing and availability**. Варианты:
- **Платная** — например 14,99 $ (Microsoft пересчитает в тенге). Можно включить бесплатный пробный
  период; чтобы он корректно ограничивал работу, программе нужна проверка лицензии магазина — скажите,
  и я её добавлю.
- **Бесплатная** — если основной доход планируется с Pro в телефонных приложениях.

## Шаг 5. Свойства и возрастной рейтинг

- **Properties**: категория — Utilities & tools (Служебные программы); адрес политики
  конфиденциальности (тот же, что для Google Play).
- **Age ratings**: анкета IARC — на всё «Нет», кроме «Приложение позволяет совершать покупки»,
  если программа платная.

## Шаг 6. Пакет

**Packages** → перетащите `SwitchFlow_<версия>_x64.msix`, собранный с вашими данными из шага 3.
Partner Center проверит пакет сразу.

## Шаг 7. Страница в магазине

**Store listings** → русский и английский:
- описание — можно взять из `docs/store/google-play-listing.md` (убрав про «Pro» и бесплатный лимит);
- скриншоты программы 1366×768 или больше (минимум 1, лучше 4): главный экран, выбор данных,
  перенос, отчёт;
- значок магазина — из `desktop/src-tauri/icons/icon.png`.

## Шаг 8. Отправка

**Submit for certification**. Проверка — обычно 1–3 рабочих дня.

**Вероятные вопросы проверяющих и ответы:**
- *runFullTrust* — классическое настольное приложение (Tauri/WebView2), работает с USB-устройствами
  и локальной сетью.
- *Установка драйвера* — драйвер USB (UsbDk, открытый, подписан Red Hat) нужен только для переноса по
  кабелю с Android; ставится по нажатию пользователя с подтверждением Windows; без него программа
  работает по Wi-Fi.
- *Файл приложения для Android внутри пакета* — это приложение-компаньон SwitchFlow для телефона
  пользователя; копируется на его телефон только по его действию.

## Обновления

Поднимите версию в `desktop/src-tauri/Cargo.toml` (и `tauri.conf.json`), соберите пакет заново и
загрузите его новой отправкой в Partner Center.
