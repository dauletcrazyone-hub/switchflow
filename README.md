# SwitchFlow

**Your data. Your devices. One seamless move.**

SwitchFlow — программа для Windows 10/11, которая переносит личные данные между
Android и iPhone: фото, видео, контакты, календари, документы и музыку. Перенос
идёт **только локально**, по зашифрованному соединению, с проверкой каждого файла
по SHA-256. Оригиналы на телефоне-источнике никогда не изменяются и не удаляются.

| Компонент | Технологии | Где лежит |
|---|---|---|
| Windows-приложение | Tauri 2, Rust, React 19, TypeScript, Tailwind CSS 4, Motion, Lucide | [`desktop/`](desktop) |
| Android-компаньон | Kotlin, Jetpack Compose, MediaStore, Contacts Provider, CalendarContract, SAF | [`android/`](android) |
| iOS-компаньон | Swift, SwiftUI, PhotoKit, Contacts, EventKit | [`ios/`](ios) |
| Документация | Реализуемость, протокол, архитектура, сборка | [`docs/`](docs) |

## Как это работает

```
 Телефон-источник ──TLS──▶  ПК (SwitchFlow)  ──TLS──▶ Телефон-получатель
   читает оригиналы        проверяет SHA-256        сохраняет через системные API,
   (только чтение)         хранит файл временно     перечитывает и подтверждает SHA-256
```

1. На ПК нажмите **«Показать QR-код»**.
2. В приложении SwitchFlow на телефоне нажмите **«Подключиться к компьютеру»** и отсканируйте код.
3. Сверьте 6 цифр на телефоне и ПК, нажмите **«Разрешить»**. Повторите для второго телефона.
4. Отметьте категории — телефон попросит доступ **только к ним**.
5. Нажмите **«Начать перенос»**. SwitchFlow проверит доступ, место и совместимость и перенесёт всё сам.
6. В конце — отчёт: сколько перенесено, сколько проверено, что повторить.

Почему через приложение-компаньон, а не просто по кабелю: Windows по USB видит у iPhone
только папку с фото **для чтения**, а записывать на iPhone могут только приложения на
самом iPhone. Подробно — в [docs/FEASIBILITY.md](docs/FEASIBILITY.md).

## Быстрый старт (разработка)

Требования для Windows-приложения: Node.js 20+, Rust stable (MSVC), Visual Studio Build
Tools с компонентом «Разработка классических приложений на C++», WebView2 (есть в Windows 11).

```bash
cd desktop
npm install
npm run tauri:dev
```

Только интерфейс в браузере (автоматически демо-режим, без телефонов):

```bash
npm run dev --prefix desktop
```

Тесты:

```bash
cd desktop && npm test && npm run typecheck
cd desktop/src-tauri && cargo test
cd android && ./gradlew testDebugUnitTest
```

## Демо-режим

Настройки → **Демо-режим**. Показывает весь путь — сопряжение, выбор данных, проверки,
перенос, отчёт — на вымышленных устройствах. Режим явно помечен на каждом экране
(значок «Демо» в заголовке, баннер, метки на карточках). Реальный режим никогда не
показывает вымышленные устройства или данные.

## Безопасность и приватность

- Данные не покидают локальную сеть; ПК не делает исходящих соединений.
- TLS 1.2/1.3; телефон доверяет только сертификату, отпечаток которого получен из QR-кода.
- Каждое новое устройство подключается только после подтверждения на ПК (6-значный код).
- SHA-256 проверяется на ПК после загрузки и на получателе после сохранения.
- Временные файлы удаляются после подтверждённой доставки; журналы не содержат имён файлов и личных данных.
- Подробно: [docs/PRIVACY.md](docs/PRIVACY.md), [docs/PROTOCOL.md](docs/PROTOCOL.md).

## Структура репозитория

```
desktop/                 Windows-приложение (Tauri 2)
  src/                   React-интерфейс: экраны, дизайн-система, i18n (ru/en/kk)
  src-tauri/src/         Rust-ядро: сервер, сопряжение, движок переноса, обнаружение USB
  src-tauri/tests/       Сквозные тесты протокола
  shared/                Таблица совместимости (общая для Rust и UI)
android/                 Приложение-компаньон Android (Kotlin/Compose)
ios/                     Приложение-компаньон iOS (Swift/SwiftUI, XcodeGen)
docs/                    Реализуемость, протокол, архитектура, сборка, статус, приватность
```

## Локализация

Русский и английский — полностью; казахский — архитектурно готов (`desktop/src/i18n/kk.ts`),
переведена часть интерфейса, остальное подставляется из русского. Чтобы добавить язык,
скопируйте `ru.ts` — TypeScript проверит, что все ключи на месте.
